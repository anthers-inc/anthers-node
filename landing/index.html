Every Account Anthers Issues Lives Here

This is anthers.social, the server Anthers runs to hold those accounts. Each one is a full identity on the AT Protocol: the handle resolves on the open network, the records stay readable by any app that speaks the protocol, and the account can move to another server with its history intact.

There is no feed to scroll here and no profile page to browse. What this server does is answer for the accounts, which is why signing in is the only way to change one.

Sign In For the holder of an account hosted here: the password, the handle, and which apps have access. Create an Account Anthers makes them at anthers.org, which also explains what an account is for.

The server's API answers under /xrpc/, and an app asking for a Personal Data Server takes anthers.social as the answer.
